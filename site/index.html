The feed — six sources, one deduplicated list, salary where it's stated. Not a screenshot: pure HTML.

Why it exists

Job hunting means six tabs, six logins, and the same posting three times.

Arbeitsagentur for Munich, four remote boards, Adzuna for the rest — each with its own search, its own noise, and the same role reposted under three names. EasyApply pulls every source with a real API into one deduplicated, newest-first feed on your Mac, and stays out of your way.

One feed, not six tabs

Arbeitsagentur, Adzuna, Arbeitnow, Himalayas, RemoteOK, WeWorkRemotely — official APIs and feeds only, no scraping. Cross-source duplicates collapse into a single row.

Salary up front

Postings that state pay get a copper badge in the feed, so you can rank before you read. Adzuna's model estimates are marked with a ~ instead of passed off as fact.

A tracker, not a spreadsheet

Interested → Applied → Interview → Rejected, with notes — attached to the posting itself. A job is never lost, and never applied to twice.

Polite and local

Per-source rate limits, spaced sequential requests, and a "via source ↗" link on every posting. Jobs live in a local database, API keys are OS-encrypted — no accounts, no telemetry.

How it works

Honest plumbing

  1. 1.Sync — the main process fetches each source on an interval, one at a time, inside its published rate limits.
  2. 2.Normalize + dedupe — six response shapes become one job model, and the same role from two boards collapses into one row.
  3. 3.Local PGlite — everything lands in a Postgres-in-a-file on your disk. Nothing leaves the machine except the API requests themselves.
  4. 4.You apply — every posting links out to the original source. Set a status, add a note, move on.

No accounts, no cloud, no telemetry. Your statuses and notes never sync anywhere.

Install

Up and running in one command

# install

brew install --cask souhaibbenfarhat/tap/easyapply

# upgrade

brew upgrade --cask easyapply

# uninstall

brew uninstall --cask easyapply

# installed manually from the dmg instead? clear Gatekeeper's

# quarantine flag once, so the app opens without a "damaged" warning

xattr -dr com.apple.quarantine /Applications/EasyApply.app

EasyApply isn't notarized by Apple (it's ad-hoc signed) — the Homebrew cask clears the quarantine flag for you on install, so the xattr line is only needed if you download the dmg from GitHub Releases yourself. Either way, you can always audit the source.
